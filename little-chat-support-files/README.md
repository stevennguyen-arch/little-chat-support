# Little Chat Support

A professional, mobile-friendly supportive chat demo for talking about feelings. It is a static webpage: there is no account system, server, API key, or paid AI service. Its replies use simple built-in patterns, so it is **not a real generative AI assistant**, therapist, or doctor. It cannot diagnose, treat, provide crisis care, or answer arbitrary questions.

## Important safety note

This is not professional help, a substitute for a qualified mental-health professional, or a source of medical advice. For ongoing or serious concerns, contact a qualified mental-health professional. If you or someone else may be in immediate danger, call your local emergency number. In the U.S. and its territories, call or text **988** or visit <https://988lifeline.org/>.

## Try it on your computer

1. Open `index.html` in a web browser (double-click it in Finder).
2. Type a message or tap one of the suggested prompts.

The demo runs locally in your browser. Your chat messages are not sent to a server and are cleared when you reload or reset the page. The crisis-response reply uses the same U.S. and territories 988 guidance; elsewhere, contact local emergency services or a local crisis line.

## Share it free with GitHub Pages

You’ll need a GitHub account. For a simple public demo:

1. Create a new **public** repository on GitHub.
2. Add this folder’s `index.html` file at the top level of the repository and commit it.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and the `/(root)` folder, then save.
5. After GitHub Pages publishes the site, copy its URL from the Pages settings and send that link to your friend.

GitHub Pages makes the page public to anyone with the link. The chat still uses only its built-in replies; hosting it does not add a real AI model. The free hosting and current setup are documented at <https://docs.github.com/en/pages/quickstart>.
